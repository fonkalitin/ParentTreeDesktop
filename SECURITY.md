# Безопасность и приватность

Приложение хранит документы и профиль рядом с EXE в ParentTreeData.
Репозиторий содержит только вымышленные примеры; пользовательские документы не входят в поставку.

Ресурсы редактора встроены в EXE. Внешние переходы, всплывающие окна и разрешения WebView2 заблокированы.
Content Security Policy запрещает соединения приложения с внешними адресами.
Приложение не содержит входа, системы аккаунтов или функции отправки деревьев.

Это не обещание отсутствия ошибок: WebView2, Windows и зависимости тоже нужно обновлять.
Документы, резервные копии и экспорт не шифруются; защищайте их средствами своей ОС.

Если нашли уязвимость, воспользуйтесь приватным security advisory на площадке публикации.
Не публикуйте в issue реальные деревья, персональные данные, пароли или файлы рабочего профиля.
Если приватного канала нет, сначала создайте issue без чувствительных подробностей с просьбой о безопасном канале.
