# Перенос на публичную площадку

Этот репозиторий создан с новой историей. Не объединяйте его со старыми рабочими репозиториями,
не импортируйте пользовательские документы и не добавляйте ParentTreeData.

1. Проверьте README, выбранную лицензию, THIRD_PARTY_NOTICES.md и docs/RELEASE_AUDIT.md.
2. Выполните тесты, сборку и tools/check_release.py.
3. Проверьте всю историю Git инструментом поиска секретов; проверьте также архив релиза и EXE.
4. Создайте пустой целевой репозиторий и отправьте только main и подготовленные теги этой чистой истории.
5. Отдельно загрузите релизные архивы, EXE при необходимости, SHA256SUMS.txt и автономный установщик WebView2.
6. Проверьте ссылки, тему репозитория и описание. CI в .github/workflows/build.yml рассчитан на Windows GitHub Actions.

Архив исходников или git clone не включает бинарные вложения релиза — перенесите их отдельно.
Сам установщик WebView2 не помещается в Git; он остаётся необязательным отдельным ZIP.
Не копируйте настройки CI, доступы или credential helper со своей машины.
