## Результат и границы

В пределах перечисленных проверок персональные сведения исходной семейной базы, секреты и внутренние адреса не обнаружены.
Это проверка конкретного состава выпуска, а не гарантия отсутствия любых ошибок.
GitHub Actions подготовлен; его запуск на целевой GitHub-площадке проверяется после переноса.
На Windows без WebView2 предусмотрено сообщение с инструкцией; удаление компонента из рабочей ОС ради проверки не выполнялось.
Неподписанный EXE может вызвать стандартное предупреждение Windows. Для скачанных файлов проверяйте SHA256SUMS.txt.

## Повторная проверка

1. npm --prefix web ci
2. npm --prefix web test
3. ./build.ps1
4. dotnet run --project tests/FileTests -c Release
5. dotnet run --project tests/WindowTests -c Release
6. python tools/check_release.py --dist dist
7. gitleaks dir . --redact
8. gitleaks git . --redact --log-opts=--all
9. npm --prefix web audit
10. dotnet list desktop/ParentTree.Desktop.csproj package --vulnerable --include-transitive

При каждом обновлении повторяйте проверки и обновляйте дату отчёта.
Не включайте в публичные отчёты найденные значения секретов или реальные документы.
