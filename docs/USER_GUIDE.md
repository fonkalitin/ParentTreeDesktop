# Работа с ParentTree

## Первое дерево

Создайте пустое дерево кнопкой «Новое» или откройте .fam кнопкой папки / Ctrl+O.
Демонстрационный файл содержит четыре бабушки и дедушки, родителей и двух детей.
Все персонажи вымышлены. Это обычный редактируемый файл без особого статуса.

## Каталог и поле

Каталог содержит всех людей документа. Перетаскивайте нужные карточки на поле.
Карточка может оставаться в каталоге, пока вы не решили, куда её поставить.
Справа редактируются имя, даты, заметки, фото и вложения. Неполные даты допустимы.

Связи родительства и брака задавайте соответствующими портами карточек.
Фантомы обозначают неопределённые связи, а контейнеры помогают группировать карточки.
Группировка сама по себе не устанавливает родство.

## Сохранение и перенос

Ctrl+S — сохранить, Ctrl+Shift+S — выбрать другой файл.
После правок действует автосохранение с задержкой 3 секунды.
Изменения в существующем документе обновляют сам файл; для нового сначала выберите имя.
Перед выключением дождитесь подтверждения записи. Регулярно сохраняйте отдельные копии.

Для обмена достаточно .fam: фото и вложения, добавленные приложением, находятся внутри него.
Для переноса программы и её настроек перенесите EXE, ParentTreeData и свои документы.
Последний путь к файлу при смене компьютера может потребовать повторного выбора через «Открыть».

## Экспорт

Кнопки PNG и PDF экспортируют вид дерева. Это иллюстрация, не замена редактируемого .fam.
Полное содержимое зависит от выбранного файла и его вложений; проверяйте экспорт перед отправкой.

## Ограничения

- Поддерживается Windows x64 с установленным Microsoft WebView2 Runtime.
- Сам EXE содержит .NET; отдельная установка .NET для пользователя не требуется.
- Папка приложения должна быть доступна для записи.
- Лимит открываемого .fam — 256 МБ.
- Очень большие деревья и встроенные фото увеличивают расход памяти и размер .fam.
- Документы, автокопии и экспорт не шифруются самим приложением.
- Не открывайте недоверенные документы без обычной осторожности.
