# Формат .fam

.fam — UTF-8 JSON. Хранит один документ:
`version`, `metadata`, `nodes`, `edges`, опционально `clusters` и `phantoms`.

metadata содержит название, временные метки, режим компоновки и placedIds — людей, вынесенных на поле.
nodes содержит карточки людей, координаты и данные. edges содержит связи parent/spouse/sibling.
clusters группирует карточки визуально. phantoms хранит неопределённые связи.

Фото и вложения сериализуются в data URL/base64. Файл можно переносить независимо от расположения исходных фото.
Перед редактированием JSON вручную создайте резервную копию. Пример — examples/Ивановы.fam.
Имена и сведения, введённые пользователем, попадают в его .fam, резервные копии и экспорт.
