ParentTree 1.2.0 — семейное древо для Windows x64

1. Распакуйте архив приложения в папку, доступную для записи.
2. Запустите ParentTreeDesktop.exe.
3. Через «Открыть» выберите свой .fam или лежащее рядом демонстрационное древо.
4. «Новое» создаёт пустое древо; Ctrl+S сохраняет, Ctrl+Shift+S сохраняет как новый файл.

Рядом с EXE создаётся ParentTreeData: настройки, резервная копия и профиль интерфейса.
Для переноса работы копируйте приложение, ParentTreeData и ваши .fam-файлы.
Не помещайте EXE в Program Files или другую папку, недоступную для записи.

Автосохранение срабатывает через 3 секунды после правки. Существующий файл обновляется.
Для нового безымянного древа сначала выберите имя через «Сохранить».
Внештатное завершение до записи последних изменений может привести к их потере.
Резервная копия безымянного древа: ParentTreeData/autosave/recovery.fam — открывается как обычный файл.

Фото и вложения хранятся внутри .fam. Древо и экспортированные файлы содержат ваши данные:
вы сами решаете, кому передавать их и где делать резервные копии.

Если нужен WebView2: распакуйте WebView2-Win10-x64.zip и запустите находящийся внутри установщик Microsoft.
После установки снова откройте ParentTree. Установщик полный, скачивание при установке не требуется.
Прямая официальная ссылка x64: https://go.microsoft.com/fwlink/?linkid=2124701

Все восемь людей в демонстрационном файле вымышлены.
