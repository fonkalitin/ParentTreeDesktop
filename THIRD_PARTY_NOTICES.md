## .NET and WebView2

.NET 10 and Windows desktop runtime notices are preserved in licenses/dotnet/. The Microsoft WebView2 SDK is referenced through NuGet; its LICENSE.txt and NOTICE.txt are retained.
WebView2 Runtime itself is installed separately; an optional companion ZIP contains the unmodified Microsoft-signed standalone installer. Its own Microsoft terms apply.
Official documentation: https://learn.microsoft.com/en-us/microsoft-edge/webview2/concepts/distribution

This inventory was generated from the locked dependencies and downloaded runtime packages used for this release. Regenerate and review it when updating dependencies.

Some build-only native bindings do not include a root license text in their npm archive. Their declared SPDX license metadata is retained in DECLARED-LICENSE.json; these build tools are not included in the desktop executable.
